# Andalan Digdaya Madani Tour & Travel – Website

Website statis (`index.html` + file logo) untuk Andalan Travel – travel umroh & haji resmi PPIU, Harapan Indah, Bekasi.

## Cara upload ke GitHub (lewat browser, tanpa coding)

1. Login ke https://github.com lalu klik **New repository**.
2. Nama repo, misalnya `andalan-travel`. Pilih **Public**. Klik **Create repository**.
3. Klik **uploading an existing file**, lalu seret **semua file** di folder ini (`index.html`, `logo.png`, `logo-icon.png`, `favicon.png`, `README.md`) ke halaman tersebut. Klik **Commit changes**.
4. Buka **Settings → Pages**. Pada *Build and deployment*, pilih **Deploy from a branch**, branch `main`, folder `/ (root)`, klik **Save**.
5. Tunggu 1–2 menit. Website aktif di `https://USERNAME.github.io/andalan-travel/`.

## Mengubah isi
Edit `index.html` langsung di GitHub (ikon pensil), lalu commit. Nomor WhatsApp, link Maps/TikTok/Instagram ada di bagian kontak.
